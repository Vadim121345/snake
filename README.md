#  Змейка на Python

Классическая аркадная игра «Змейка», реализованная на Python с использованием библиотеки Pygame.

##  Описание

Игрок управляет змейкой, которая постоянно движется по игровому полю. Цель — съедать появляющуюся еду, расти в длину и набирать очки, не врезаясь в стены и в собственное тело. С каждым съеденным яблоком змейка становится длиннее, а игра — сложнее.

##  Возможности

- Управление стрелками и клавишами WASD
- Случайное появление еды в свободных клетках
- Рост змейки и подсчёт очков
- Определение столкновений со стенами и с самим собой
- Перезапуск игры без выхода из программы (`R`)
- ащита от разворота на 180° за один ход
- Визуальное разделение головы и тела змейки
